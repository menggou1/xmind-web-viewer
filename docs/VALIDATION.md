## 已实现

- React + TypeScript + Vite 项目，原始文件保留，构建时解析并自动生成目录、独立导图 JSON 与图片资源。
- 现代 JSON 与旧版 XML、多画布、完整标题/换行/父子顺序/备注/超链接/原始折叠信息；其他原始元数据保留。
- 独立概要模型及 SVG 括号。部分范围、单节点范围、多个范围、包含和交叠范围、概要后代及长概要均覆盖；概要采用独立布局通道。

- 搜索全部画布及隐藏节点、匹配计数与前后切换、自动切换画布/展开祖先/定位、清除后恢复当前画布状态。
- 图片懒加载、独立资源与缓存、大图查看、缩放/拖动/关闭、原图入口。
- GitHub Light / Dark / 跟随系统，保存选择，图片查看器同步主题；桌面及手机布局。
- 文件夹分类、名称搜索及排序、自动统计、Git 可确认时显示更新时间。
- 目录/画布/节点分享链接，Hash 路由直接打开和刷新，项目子路径适配。

## 性能记录

一次本机构建中，全部 18 份文件的解析（含 ZIP 读取、CRC、像素解码验证、图片提取）合计约 **589 ms**；其中脂质约 **169 ms**，微生物学第二章约 **220 ms**。这是单次参考值，随机器、文件和缓存变化，不是性能保证。

另有实际生成并解析的压力样本：**501 个节点、15 层、25,236,880 字节 Xmind 归档、4096 × 2048 的约 24 MiB PNG**。图片确实被节点引用、完整解码验证并提取，并非仅塞入未读取的大附件。该次解析约 **207 ms**，完全展开的纯布局约 **1.26 ms**，无节点重叠。纯布局数值不包含浏览器 DOM 测量与 React Flow 渲染；压力样本的节点尺寸使用测试输入，浏览器另以真实文件验证实际卡片测量和交互。

真实脂质与微生物学第二章的生成 JSON 分别约 154 KiB、163 KiB，原图独立存储。生产目录约 5.74 MiB（包含所有导图、图片、报告和前端资源）。打开目录只请求索引，进入导图后才加载该导图数据；最近 4 份缓存于内存。超过 200 个节点默认展开至第 2 级，不丢弃隐藏正文或图片，可全部展开。

## 兼容范围与限制

1. **格式而非软件版本承诺**：真实验证了现有 18 份 `content.json` 文件；`content.xml` 有命名空间、换行、概要、图片、多画布与折叠的合成测试。无法据此保证所有历史或未来 Xmind 变体都兼容。
2. **图片**：当前真实样本的 15 张图片均正常提取、解码。支持 PNG/JPEG/GIF/WebP/AVIF；TIFF 生成显示副本并保留原始文件。SVG 主动拒绝，其他不支持或损坏资源显示占位并生成报告，不会假装图片成功。
3. **外观还原**：章节、节点、图片和概要语义优先。边界框、标记图标、原始样式、数学公式专用渲染及部分扩展外观暂未还原，原始元数据保留；识别到不支持的边界/标记/扩展时会报告。自由主题和标注使用独立虚线关系；关系线保留语义，未实现复杂关系线避让优化。
4. **布局取舍**：多个概要使用独立右侧通道，横向宽度可能较大。概要覆盖分支的可见子树范围，折叠后重新计算；不会模仿原始自由摆放坐标。
5. **手机范围**：已在 Windows Edge 的 Android Pixel 7 视口与触控模拟中测试；尚未进行实体 Android 手机验收，也未实测所有浏览器及老旧设备。
6. **规模范围**：18 份真实样本及 501 节点/15 层/约 24 MiB 合成文件通过；未声称已测试 100 份、万级节点或所有极端概要组合。
7. **链接稳定性**：普通改名、移动、正文编辑保持 ID；重建首画布/根节点 ID、改变首画布或删除文件可能使旧链接失效。没有设置人工别名跳转表。
8. **内容更新**：生产环境推送后自动构建发布；本地修改 `.xmind` 后需再次运行内容构建或重启开发命令，当前没有文件系统热监控器。
